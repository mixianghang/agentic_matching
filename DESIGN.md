# Agentic Matching System - 系统设计文档

## 1. 系统概述

一个基于智能体对话的需求匹配系统，替代传统电商、交友、找房等平台，让智能体代表用户完成长序列交互任务。

### 核心理念

- **用户代理**：每个用户有一个或多个智能体作为线上代表
- **自然语言交互**：通过聊天而非表单来定义需求
- **智能匹配**：智能体通过多轮对话寻找匹配方并协商细节
- **持续运行**：任务一直运行直到用户标记完成

### 2.2 核心组件

#### 2.2.1 User Agents（用户代理）
- Web 聊天窗口
- 微信公众号
- Telegram Bot
- 功能：
  - 发起新请求
  - 查看任务列表
  - 查看任务进展
  - 与智能体直接对话

#### 2.2.2 Backbone（多智能体系统）
- 基于大模型的对话系统
- 需求处理智能体
- 匹配协商机制
- 用户信息管理

#### 2.2.3 Task Workflows（任务工作流）
- 相亲工作流
- 租房工作流
- 游戏组队工作流
- 可扩展的工作流框架

#### 2.2.4 Tools（工具组件）
- 人脸识别
- 身份验证
- 房产验证
- 可扩展工具列表

## 3. 数据模型

### 3.1 User（用户）
```python
class User:
    id: str
    username: str
    email: Optional[str]
    created_at: datetime
    preferences: Dict
    private_info: Dict
```

### 3.2 Agent（智能体）
```python
class Agent:
    id: str
    user_id: str
    role: str  # "user_agent", "task_agent", "matching_agent"
    created_at: datetime
    active: bool
```

### 3.3 Task（任务）
```python
class Task:
    id: str
    user_id: str
    agent_id: str
    task_type: str  # "dating", "rental", "gaming"
    description: str
    requirements: Dict
    status: TaskStatus
    created_at: datetime
    matched_task_ids: List[str]
    messages: List[Message]
```

### 3.4 Message（消息）
```python
class Message:
    id: str
    sender_id: str
    receiver_id: Optional[str]
    content: str
    timestamp: datetime
    is_public: bool
```

## 4. 前端界面设计

### 4.1 布局结构

```
┌────────────────────────────────────────────────────────────┐
│                        顶部导航栏                            │
├──────────┬───────────────────────────┬─────────────────────┤
│          │                           │                     │
│  任务    │      聊天区域             │    信息面板         │
│  列表    │                           │                     │
│          │  - 消息历史               │  - 需求详情         │
│          │  - 输入框                 │  - 匹配结果         │
│          │                           │  - 协商记录         │
└──────────┴───────────────────────────┴─────────────────────┘
```

### 4.2 界面流程

1. **登录/注册** → 独立的认证界面
2. **任务列表** → 左侧边栏，显示所有任务
3. **聊天界面** → 中央区域，对话式交互
4. **详情面板** → 右侧，显示任务相关信息

## 6. 技术栈

### 6.1 后端
- **FastAPI** - Web 框架
- **Pydantic** - 数据验证
- **OpenAI API** - 大模型支持
- **Python-dotenv** - 环境变量管理

### 6.2 前端
- **原生 HTML/CSS/JS** - 无框架依赖，轻量快速
- **响应式设计** - 支持多设备

### 6.3 存储（未来）
- **SQLite/PostgreSQL** - 关系型数据库
- **Redis** - 缓存和会话管理
